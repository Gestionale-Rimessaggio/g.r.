# Gestionale Rimessaggio

Gestionale web per cantieri e rimessaggi nautici: barche, lavori, scheda lavoro, programma, scadenze, mappa del cantiere, magazzino.
Al primo accesso l'amministratore sceglie nome dell'azienda, colori, loghi, luogo del meteo e sezioni (Altro › Aspetto dell'app).

I dati stanno nel progetto Firebase indicato in `config.js`; le regole di sicurezza sono in `firestore.rules`.
